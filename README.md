# AI Assistant

A production-grade AI assistant built from scratch, following a 20-phase
roadmap. See the current phase below.

## Status

- **Phase 2 (Backend Development)**: Milestone 3 complete — durable
  sessions: per-session files (`data/sessions/<id>.json`), restart
  recovery, session_id whitelist (path-traversal defense), injected
  service for testable temp-dir storage. 53 passing tests.
- **Phase 2, Milestone 2**: `POST /chat` + `GET /history` with
  thread-safe in-memory sessions.
- **Phase 2, Milestone 1**: FastAPI skeleton + `/health` + venv.
- Phase 1 (Programming Fundamentals) complete — REPL assistant with
  persistent memory, exception hierarchy, atomic file writes, git/GitHub.

## Requirements

- Python 3.12+ (verified with 3.14)

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
```

## Run the web server

```powershell
.\.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

- Health check: <http://127.0.0.1:8000/api/v1/health>
- Interactive API docs (auto-generated by FastAPI): <http://127.0.0.1:8000/docs>

## API examples

Chat with session `demo`:

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/chat `
  -ContentType "application/json" `
  -Body '{"session_id":"demo","message":"hello"}'
```

Read that session's history:

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/v1/history/demo
```

## Run the CLI (Phase 1 assistant)

```powershell
.\.venv\Scripts\python -m app.cli
```

## Test

```powershell
.\.venv\Scripts\python -m unittest discover -s tests -v
```

## CLI usage

```
You> HELLO!!
Hello! I'm Aria. How can I help?
You> what is your name
My name is Aria.
You> /stats
I remember 4 messages (user=2, assistant=2) across my sessions.
You> /about
I am Aria, version 0.1.0. Currently: Phase 1 - Programming Fundamentals.
You> /help
Commands: /help  /stats  /about  /exit
You> /exit
```

Conversations are saved to `data/history.json` and reloaded on the next
start — the seed of long-term memory. The web server will grow
per-session persistence in Phase 2, Milestone 3.
